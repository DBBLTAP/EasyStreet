🔨 Scripts — Run these directly from the scripts\ folder
✅
install-server.bat
First-time install. Downloads SteamCMD and all DayZ server files (~3 GB). Run as Admin.
scripts\install-server.bat
🚀
start.bat
Launches your DayZ server. Edit the MODS line inside it to add your mods.
scripts\start.bat → copy to C:\DayZServer\
🔄
restart.bat
Backs up player data, stops server, and restarts it. Schedule with Task Scheduler every 4 hours.
scripts\restart.bat → copy to C:\DayZServer\
🧩
install-mod.bat
Interactive mod installer. Enter a Workshop ID and it downloads, copies, and sets up the mod for you.
scripts\install-mod.bat
🔄
update-server.bat
Stops server, downloads the latest DayZ server patch, and restarts. Run after every DayZ update.
scripts\update-server.bat
💾
backup.ps1
PowerShell backup script. Saves player data to C:\DayZBackups\ and keeps the last 24 backups.
scripts\backup.ps1 → copy to C:\DayZServer\
🔥
open-firewall-ports.bat
Opens all DayZ ports (2302-2306) in Windows Firewall. Run as Admin on every new PC.
scripts\open-firewall-ports.bat
📄
mod-list-template.txt
Blank template to plan your mod list. Includes all popular mod IDs and load order rules.
configs\mod-list-template.txt
📄 Config Files — Edit these then copy to C:\DayZServer\
⚙
serverDZ.cfg
Your main server config. Change hostname, passwordAdmin, maxPlayers, and map before using.
configs\serverDZ.cfg → C:\DayZServer\serverDZ.cfg
🛡
BEServer_x64.cfg
BattlEye RCON config. Change the RConPassword then copy to the battleye\ folder after first server run.
configs\BEServer_x64.cfg → C:\DayZServer\battleye\
💡
New PC Setup? Start by running scripts\install-server.bat as Administrator — it installs SteamCMD, downloads the server files, creates all folders, and copies config files automatically. Then open the Full Setup Guide above and follow Chapter 1 onwards. The whole process takes about 2-3 hours start to finish.
